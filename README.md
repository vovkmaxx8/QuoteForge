QuoteForge — Генератор случайных цитат на 7 языках
QuoteForge — коллекция из семи независимых реализаций генератора случайных цитат. Каждая версия работает на своём языке программирования и предлагает богатый функционал: от простого вывода цитаты до управления собственной коллекцией, поиска, избранного и экспорта.

✨ Уникальные возможности (общие для всех версий)
📚 Встроенная база цитат (50+ цитат известных личностей).

🎲 Генерация случайной цитаты (с автором).

🔍 Поиск цитат по автору или ключевому слову.

➕ Добавление новых цитат в локальную базу (сохранение в файл).

⭐ Избранное — сохранение понравившихся цитат.

💾 Экспорт цитаты в текстовый файл.

📊 Категории (мотивация, мудрость, юмор, любовь, успех, жизнь).

🔄 Повторный вывод без перезапуска.

🖥️ Интерфейсы:

Командная строка (CLI) с интерактивным меню.

Веб-интерфейс в PHP и JavaScript.
